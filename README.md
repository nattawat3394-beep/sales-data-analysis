# 📊 Sales Data Analytics & Pristine Data Cleaning Dashboard
> ระบบวิเคราะห์ข้อมูลยอดขายและคัดกรองข้อมูลขยะ 7 จุดอย่างเข้มงวด (Deep Forensic Data Cleaning)

เว็บแอปพลิเคชันสำหรับแสดงผลการวิเคราะห์ข้อมูลยอดขาย จากชุดข้อมูลดิบ 10,000 รายการ (2024 - 2025) ที่ผ่านกระบวนการ **Data Cleaning คัดกรองข้อมูลขยะและความผิดปกติครบทั้ง 7 จุด** เพื่อให้ได้ข้อมูลยอดขายจริงที่ถูกต้องแม่นยำ 100%

## 🎯 สรุปผลการคัดกรองข้อมูลขยะ 7 จุด (7 Garbage Points Audit & Removal)

จากการตรวจสอบอย่างละเอียด พบข้อมูลขยะและความผิดปกติทั้งหมด **7 จุด** ดังต่อไปนี้:

| จุดที่ | ประเภทข้อมูลขยะ / ความผิดปกติ | จำนวนที่ตรวจพบ | มูลค่าที่เกี่ยวข้อง | เหตุผลทางธุรกิจที่ต้องคัดออก |
| :---: | :--- | :---: | :---: | :--- |
| **1** | **สถานะคำสั่งซื้อ "ยกเลิก"** | 471 รายการ | ฿520,226.00 | ลูกค้ายกเลิกคำสั่งซื้อ ไม่มีการชำระเงินจริงและไม่เกิดการส่งมอบสินค้า |
| **2** | **สถานะคำสั่งซื้อ "คืนสินค้า"** | 284 รายการ | ฿282,428.75 | ลูกค้าส่งคืนและได้รับเงินคืน ต้องตัดออกจากยอดขายสุทธิ |
| **3** | **หน้าร้าน + เก็บเงินปลายทาง (COD Anomaly)** | 402 รายการ | ฿415,860.00 | ซื้อหน้าเคาน์เตอร์แต่ระบุเก็บเงินปลายทาง เกิดจากแคชเชียร์บันทึก POS ผิด |
| **4** | **หน้าร้านนอกเวลาทำการ (22:00 - 07:59 น.)** | 501 รายการ | ฿528,710.00 | มีการบันทึกการซื้อหน้าร้านตอนตี 1 - ตี 4 ซึ่งเป็นเวลาร้านค้าปิดทำการ |
| **5** | **ผู้เยาว์ (< 18 ปี) ชำระด้วยบัตรเครดิต** | 256 รายการ | ฿289,340.00 | ขัดต่อกฎหมายและระเบียบธนาคารพาณิชย์ (อายุ 15 ปี ไม่สามารถเปิดบัตรเครดิตหลักได้) |
| **6** | **ข้อมูลเพศไม่ระบุ ("ไม่ระบุ")** | 197 รายการ | ฿211,430.00 | ข้อมูลประชากรไม่สมบูรณ์ ขาดความพร้อมในการนำไปวิเคราะห์ Segment |
| **7** | **ธุรกรรมชนเวลาต่างสถานที่พร้อมกัน (Burst)** | 2 รายการ | ฿1,296.25 | ลูกค้าคนเดียวกันสั่งซื้อที่หน้าร้านและโซเชียลในนาทีเดียวกัน (เป็นไปไม่ได้ทางกายภาพ) |

> 📌 **หมายเหตุ:** เมื่อนำข้อมูลทั้ง 7 จุดนี้มารวมกันและหักรายการที่ซ้ำซ้อนออก (Deduplication) จะได้ **ข้อมูลขยะสุทธิ 1,901 รายการ (19.01%)**
