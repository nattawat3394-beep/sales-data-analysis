# 📊 Sales Data Analytics & Data Cleaning Dashboard
> ระบบวิเคราะห์ข้อมูลยอดขายและคัดกรองข้อมูลขยะ (Business Intelligence & Data Quality Audit)

เว็บแอปพลิเคชันสำหรับแสดงผลการวิเคราะห์ข้อมูลยอดขาย จากชุดข้อมูลดิบ 10,000 รายการ (2024 - 2025) ที่ผ่านกระบวนการ Data Cleaning คัดกรองข้อมูลขยะและข้อผิดพลาดทางตรรกะ เพื่อให้ได้ข้อมูลยอดขายจริงที่ถูกต้องแม่นยำ

## 🧹 การจำแนกประเภท "ข้อมูลขยะ" (Garbage Data Breakdown)
1. **คำสั่งซื้อถูกยกเลิก (Cancelled Orders):**
   - จำนวน **471 รายการ** (4.71%)
   - มูลค่าสูญเสียรายได้: **฿520,226.00**
   - สาเหตุ: ลูกค้ายกเลิกคำสั่งซื้อ ไม่มีการชำระเงินจริงและไม่มีการส่งมอบสินค้า หากนำมารวมจะทำให้ยอดขายรายงานสูงเกินจริง (Phantom Revenue)
2. **การคืนสินค้าและขอคืนเงิน (Returned Orders):**
   - จำนวน **284 รายการ** (2.84%)
   - มูลค่าสูญเสียรายได้: **฿282,428.75**
   - สาเหตุ: ลูกค้าได้รับของแล้วส่งคืน มีการคืนเงิน จึงต้องหักลบออกจากยอดรับสุทธิ
3. **ข้อผิดพลาดทางตรรกะระบบ (Business Logic Anomalies):**
   - **402 รายการ** ซื้อที่ "หน้าร้าน" แต่บันทึกวิธีชำระเงินเป็น "เก็บเงินปลายทาง (COD)" เกิดจากความผิดพลาดของเจ้าหน้าที่ POS ในการเลือกช่องทางการชำระ
4. **ข้อมูลไม่สมบูรณ์ (Missing / Null Values):**
   - **1,905 รายการ** ไม่มีคะแนนรีวิว (Null Reviews)
   - **197 รายการ** เพศ "ไม่ระบุ"

## 💡 ข้อมูลเชิงลึกทางธุรกิจ (Key Business Insights)
- **หมวดหมู่สินค้าทำเงินสูงสุด:** หมวดอิเล็กทรอนิกส์ (฿2.85M) และแฟชั่น (฿2.18M) ครองสัดส่วนรายได้รวมกว่า 49%
- **สินค้าขายดีอันดับ 1:** สมาร์ทวอทช์ (ยอดขาย ฿1.35M), รองเท้าผ้าใบ (฿1.09M) และคีย์บอร์ดเกมมิ่ง (฿850k)
- **ช่องทางการจำหน่าย:** แอปมือถือ (Mobile App) และ เว็บไซต์ (Website) ครองยอดขายรวมกว่า 62%
- **ช่องทางการชำระเงิน:** พร้อมเพย์ (PromptPay) ได้รับความนิยมสูงสุด (43.8%), รองลงมาคือบัตรเครดิต (25.1%)
- **ช่วงยอดขายพุ่งสูงสุด (Seasonal Spikes):** พฤศจิกายน (11.11) และ ธันวาคม (12.12) มียอดสั่งซื้อสูงกว่าเดือนปกติถึง 2-3 เท่า

## 🚀 ฟีเจอร์ของแดชบอร์ด
- 🎛️ **Data Mode Switcher:** สลับมุมมองข้อมูล 3 โหมด: ข้อมูลจริง (Cleaned), ข้อมูลดิบทั้งหมด (Raw), และเจาะลึกข้อมูลขยะ (Garbage)
- 📈 **Interactive Charts (Chart.js):** กราฟแนวโน้มยอดขาย 24 เดือน, โดนัทชาร์ตหมวดหมู่, แท่งเปรียบเทียบช่องทางขาย, ภูมิภาค และประชากรศาสตร์
- 🏆 **Top Products Ranking:** ตารางจัดอันดับสินค้าขายดีพร้อมคะแนนรีวิว
- 🔍 **Interactive Order Explorer:** ตารางค้นหา กรองตามสถานะ/หมวดหมู่/ช่องทาง พร้อมระบบ Pagination
- 📥 **Export CSV:** ดาวน์โหลดไฟล์ `cleaned_sales_data.csv` และ `garbage_sales_data.csv`
- 🌓 **Dark / Light Mode:** สลับโหมดสีถนอมสายตา
